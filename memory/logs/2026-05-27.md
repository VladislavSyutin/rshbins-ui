### Запрос

Разработать legacy RadioGroup на основе modern-and-legacy legacy reference, обновить память, commit и push.

### Итог

Добавлен `legacy/components/radio-group/` как React 17/plain CSS компонент для ФОС: самодостаточный `RadioGroup` с внутренним radio option, PropTypes, `dataId -> data-id`, controlled/uncontrolled режимами, `onChange(value, event)`, vertical/horizontal layout, Storybook playground/overview/states и экспортами из `src/index.*`. Disabled и long-label stories убраны по пользовательской правке; horizontal overview размещён под vertical, чтобы подписи не переносились слишком сильно.

### Изменённые файлы

- `.storybook/main.ts`
- `legacy/components/radio-group/`
- `src/index.js`
- `src/index.d.ts`
- `memory/knowledge/concepts/radio-group-single-select-control.md`

### Решения

- Для legacy/FOS не создавать отдельный публичный `Radio`, пока он не используется отдельно; держать radio option внутри `RadioGroup`.
- Storybook для review должен показывать только полезные сценарии: playground, vertical/horizontal overview и состояния без лишних disabled/long-label кейсов.
- Horizontal overview лучше располагать под vertical, а не в соседней узкой колонке.

### Риски

- Storybook и typecheck подтверждают review surface, но не заменяют отдельную проверку в реальном Webpack 3/Babel окружении ФОС.

### Follow-ups

- После ФОС review уточнить, нужен ли отдельный legacy `Radio` как публичный primitive или текущего самодостаточного `RadioGroup` достаточно.

### Запрос

Разработать legacy Tabs для FOS по modern-and-legacy reference, упростить контракт, довести Storybook review surface, затем обновить память, commit и push.

### Итог

Добавлен legacy Tabs как React 17/plain CSS tablist с приватным tab item внутри `Tabs.jsx`, PropTypes, `dataId -> data-id`, controlled/uncontrolled API и экспортами из `src/index.*`. Из публичного API убран `activationMode`; Storybook подключён через `.storybook/main.ts` и сужен до полезных сценариев: overview без long-label блока, states с одиночными active/inactive табами и выравниванием focused preview.

### Изменённые файлы

- .storybook/main.ts
- legacy/components/tabs/Tabs.jsx
- legacy/components/tabs/styles.css
- legacy/components/tabs/index.js
- legacy/components/tabs/index.d.ts
- legacy/components/tabs/Readme.md
- legacy/components/tabs/Tabs.stories.tsx
- src/index.js
- src/index.d.ts
- memory/knowledge/concepts/tab-navigation-control.md

### Решения

- Для legacy/FOS Tabs публичный API ограничен одним `Tabs`; внутренний tab button остаётся приватным и не экспортируется отдельно.
- `activationMode` удалён из runtime, типов и Storybook: стрелки сразу переключают активную вкладку, что делает контракт проще для FOS.
- Storybook states для Tabs не должны полагаться на single-option `Tabs` для inactive preview; для одиночного inactive tab лучше рендерить визуальный item напрямую.

### Follow-ups

- После review уточнить, нужен ли вообще отдельный public legacy `Tab` в будущем или одного `Tabs` достаточно.
