   - **Повреждённый npm-кэш**: несколько пакетов (`default-browser`, `ast-types` и др.) устанавливались только с `package.json` без кода. Решение — `npm cache clean --force` + `npm install --prefer-online`.

### Решения

- **Storybook 10 требует Vite 7**, не Vite 8 — держать `vite` зафиксированным на `^7.x` до официальной поддержки rolldown
- При сломанном npm-кэше (`packages installed without dist/`) помогает `npm cache clean --force && npm install --prefer-online`
- `estree-walker@2.0.2` — сломанный пакет на npm; обходится через `overrides` на v3 (API совместим для use-case `@rollup/pluginutils`)
- Дубли файлов с пробелом в имени (`Name 2.ext`) — артефакты macOS Finder или ошибочного копирования; нужно удалять
