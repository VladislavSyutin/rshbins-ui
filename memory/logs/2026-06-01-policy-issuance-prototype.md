- Цена в `.Total` переведена на regular Ubuntu, чтобы знак рубля не выбивался из шрифта.
- "Изменить номер телефона" выровнено отдельным left-aligned text link.
- Повторные проверки: `npm run typecheck` и `npm run build-storybook` успешно.

## Коммит: сценарий настройки и подтверждения телефона

- Добавлен интерактивный сценарий для продукта `Страхование от несчастных случаев для всей семьи`: переход с карточки на экран настройки, режимы `Для себя` / `В подарок`, phone-step и code-step.
- Для подарочного сценария подключены готовые поля `InputSurname`, `InputName`, `InputMiddleName`, `InputBirthDate` и `Gender`; gender не активен по умолчанию.
- Кнопка `Продолжить` на phone-step активируется только после заполнения телефона, всех обязательных полей и чекбокса согласия.
- При вводе телефона submit показывает loading 3 секунды; телефон во время loading не блокируется, а disabled-вид телефона используется только после перехода на code-step.
- На code-step добавлены `InputCode`, таймер повторной отправки кода, resend-ссылка с success toast и left-aligned ссылка `Изменить номер телефона`.
- Добавлена таблица тарифов и пересчёт `.Total` для индивидуального/семейного тарифа, 1/2 лет и четырёх страховых сумм; при 2 годах показывается старая цена.
- Период страхования считается с завтрашнего дня на выбранный срок.
- Select/dropdown реализован локально в прототипе с разворотом стрелки при открытии и без подсветки стрелки на hover.
- Divider оставлен только в режиме `Для себя`; отступы до и после divider выставлены по 16px.
- Цена в `.Total` переведена на `subheading-1-emphasized`, знак рубля наследует тот же стиль без отдельного шрифтового хака.
- Документ получил hover/pressed фон как у secondary-кнопки.
- Скролл перенесён под fixed header: прокручивается `main`, хедер остаётся над scroll-area, нижний отступ формы сохранён.
- Из ипотечной карточки удалён текст про сервис `Лёгкая ипотека`.
