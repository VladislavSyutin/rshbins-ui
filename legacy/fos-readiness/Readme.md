# FOS Readiness

Эта директория — точка сбора артефактов и заметок о готовности компонентов к внедрению в FOS (Front-Office System).

Назначение: здесь хранятся контракты, чеклисты и аудиты, описывающие, насколько компоненты из `legacy/components/` соответствуют требованиям FOS-интеграции.

Подробнее о концепции: [`memory/knowledge/concepts/`](../../memory/knowledge/concepts/).
