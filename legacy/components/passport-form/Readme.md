# PassportForm

Публичная управляемая группа полей. Получает `value` (объект данных) и вызывает `onChange` с новым полным объектом. Форма не отправляет запросы и не хранит данные между экранами. `title` и `description` позволяют менять заголовок и пояснение. `dataId` задаёт корневой `data-id` и префикс идентификаторов полей.

Использует существующие и новые legacy-поля; оформление перенесено из PassportForm прототипа в локальный CSS. `styles.css` не зависит от стилей прототипа. React 17, PropTypes, classnames, plain CSS.

Согласие и кнопки навигации остаются у родительского экрана. Родитель проверяет полноту данных перед отправкой; поля показывают собственные ошибки после blur.
