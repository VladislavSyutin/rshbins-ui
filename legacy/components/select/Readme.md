# Select

Общий выбор одного значения из `options: [{value, label, disabled?}]`. Управляемый режим `value` + `onChange(value)`; неуправляемый — `defaultValue`. `dataId` → `data-id` на управляющей кнопке. Дополнительные HTML-props относятся к корневому div.

Enter/Пробел открывает меню или выбирает пункт. Стрелки обходят доступные пункты, Home/End выбирают начало/конец, Escape и Tab закрывают меню. Фокус остаётся на combobox; активный пункт связан через aria-activedescendant. Клик снаружи закрывает меню. Поддержаны disabled, invalid/helperText и required.

Стили и геометрия перенесены из PolicySelect; стрелка повторяет исходный вид. Тарифная логика остаётся у экрана. React 17; новые зависимости не нужны.

Обводка активного пункта появляется после начала клавиатурного управления. Открытие кликом и наведение мышью не показывают эту обводку; зелёное выделение выбранного значения сохраняется.
