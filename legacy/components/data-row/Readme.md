# DataRow

Универсальная строка «подпись + значение» с разделителем. `label`, `value` и `emptyValue` принимают ReactNode. Пустое значение отображается как «Не указано», числовой ноль сохраняется. Форматирование ФИО, дат и телефона выполняет родитель. `dataId` → `data-id` на корневом элементе.

Стили перенесены из CheckDataRow прототипа, используют токены; длинное значение переносится. React 17, PropTypes, classnames, plain CSS.
