# ProductCard

Карточка продукта с изображением, заголовком, акцентом и текстом либо списком `bullets`. Кнопки «Рассчитать стоимость» и «Подробнее» вызывают `onCalculate` и `onDetails` через props, без внутренней навигации. Без обработчика кнопки остаются активными и ничего не делают. Подписи можно менять; `imageAlt` по умолчанию пустой для декоративной картинки.

`dataId` → корневой `data-id` и идентификаторы кнопок с суффиксами `-calculate` и `-details`. Использует Card/Button. Стили перенесены из PolicyCard, на узкой ширине картинка переходит вниз. React 17, PropTypes, classnames, plain CSS.

В Storybook пример повторяет содержимое и ширину карточки из прототипа: 1156 px. В узком Docs Canvas доступна горизонтальная прокрутка; карточка сохраняет исходную геометрию и полные подписи кнопок.
