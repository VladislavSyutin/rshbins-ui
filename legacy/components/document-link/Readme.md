# DocumentLink

Плитка документа: `title`, необязательный `fileSize`, обязательный `href`. Настоящая ссылка открывает файл в новой вкладке с `noopener noreferrer`. Текст сокращается многоточием, полный строковый заголовок доступен через title. `dataId` → `data-id`.

В прототипе передан URL правил страхования от пользователя. Контент и адрес файла компонент не хранит. Исходная иконка и стили Documents перенесены в компонент, оформление использует токены.
