# PolicySummary

Публичная карточка сводки. Принимает готовые значения `title`, `tariff`, `term`, `sum`, `premium` и необязательную старую цену `oldPremium`. Вычисление стоимости и скидки выполняет экран, поэтому компонент подходит разным страховым продуктам.

Премия выводится в рублях с русским форматированием. `dataId` → корневой `data-id`. Использует Card и токены; стили перенесены из Total/SummaryItem. Строки сводки остаются внутренними деталями. React 17, PropTypes, classnames, plain CSS.
